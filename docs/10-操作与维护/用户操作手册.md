## 开始聊天

打开客服页面，在输入框填写问题，点击发送或按Enter；Shift+Enter换行。快捷提问会填入问题，仍需发送。输入限制1至6000字符，不能只有空白。

可询问商品详情、按预算/颜色推荐、比较两个具体商品、查看下一批，也可闲聊。对象不明确时，请按提示提供商品编号、完整名称或明确选中哪一款。

示例：先发送“推荐300元以内的黑色耳机”，接着说“预算提高到500元”，再说“颜色不限”。系统会更新条件并沿用仍有效的信息。需要新的候选时说“下一批”；只展示本次核实结果和是否还有更多，不是全商城精确总数。价格、可售状态以下单时为准，不能据此推断库存数量或发货时效。

## 回复、停止与窗口

准备回复期间会等待路由和必要的查询/审核。闲聊先完整生成并检查是否编造商品，审核后逐步显示；这不表示未经审核的token实时外发。商品咨询/对比可收到实时分片。系统启用减少动态效果或页面隐藏/窗口收起时，不等待打字动画。

点击停止，会中止本轮等待/展示，保留已显示内容；已经发生的模型费用和持久化写入不保证撤销。收起窗口只隐藏界面，不等于停止；展开后继续查看结果，收起期间完成会有提示。

## 会话与恢复

“新会话”切换到独立上下文，旧条件不会作为新会话偏好。相同标签页刷新时保留其会话凭证，但页面不会重新列出历史消息；模型可继续使用后台保存的同会话上下文。新会话操作不是删除服务器历史。

同一会话上一轮未结束时，新请求会被提示稍后再发，不会排队代为执行。服务重启后，同一数据库、同一签名密钥及有效会话凭证是恢复上下文的条件；不承诺关闭浏览器后自动恢复所有会话。

当前凭证只是匿名会话凭证，不是商城账号。不要分享会话凭证，不在聊天中提供密码、验证码或他人的私密订单信息。

## 当前不支持

订单/物流、正式政策和真实转人工尚未接入；识别到意图后会明确提示，请使用商城已有官方入口。退款执行、取消订单、修改地址、支付等写操作不由此Agent完成。不能查询他人的私密信息或绕过权限。

## 常见提示

| 提示 | 操作 |
| --- | --- |
| 请新建会话后重试 | 新建会话，再发送问题；若持续发生联系维护人员检查签名配置 |
| HTTP404或客服服务地址异常 | 确认端口指向本项目；8000可能被其他项目使用，不要在错误服务反复发送 |
| 本轮服务异常/连接中断 | 已显示部分保留；记录请求编号交给维护人员，确认状态后重试 |
| 本轮处理已停止/预算不足 | 缩小问题范围再试，不表示未完成的任务已执行 |
| 暂无符合条件商品/资料不足 | 放宽条件或补充商品编号；不能把缺资料当成商品不存在或确定无库存 |
