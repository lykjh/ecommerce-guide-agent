## 1. 接口补充清单

本轮刻意不写 Swagger、HTTP 路径、方法、函数签名、参数 schema 或返回结构。补充材料后，再把 [01](01-requirements.md) 的 T01–T07 映射为正式工具契约。

| 待补项 | 需要确认的内容 | 影响 |
| --- | --- | --- |
| 商城身份 | 登录校验、可信主体传递、会话恢复、退出/换号 | 权限、状态隔离 |
| 商品 | 商品与 SKU 标识、筛选条件、分页、价格口径、上下架、可公开库存 | 咨询、推荐、对比 |
| 订单 | 本人查询能力、归属校验、状态含义、物流、脱敏字段 | 查单与输出准确性 |
| 人工 | 现有接待系统、创建与查状态、去重支持、接管/结束事件、离线留言 | 转人工是否能闭环 |
| 政策材料 | 内容负责人、版本、生效时间、适用范围、例外规则 | RAG 质量与更新 |
| 模型服务 | 实际部署、usage、超时/重试行为、计费、配额 | 预算与评测 |
| 部署 | 单/多实例、存储、网关、并发、保留要求 | 串行化、限流与生产选型 |
| 商城容量 | 现有流量/SLO、接口 SQL 展开、索引与缓存、连接池、数据库水位、超时取消能力 | 下游调用/并发额度、数据库影响验收 |

接口确认时至少补：参数验证、身份来源、响应语义、空结果、业务失败、技术错误、超时、幂等及权限约束，并关联 T ID 和 E 用例。不得把模型自报的用户身份映射成可信登录身份。

## 2. 存储逻辑模型（不确定建表）

优先复用既有商城或 LangGraph 存储，不为文档中的每个对象新增一张表。

| 逻辑对象 | 最小内容 | 约束 |
| --- | --- | --- |
| 会话 | 归属、身份版本、人工状态、创建/更新、状态版本 | 读取和恢复均鉴权；换身份清理敏感上下文 |
| 消息与业务状态 | 有限消息窗口、摘要、候选商品/订单、待澄清、偏好 | 裁剪与业务保存分开；不能只保留自然语言摘要 |
| 请求执行账本 | request ID、预算预留/用量、退出原因、版本 | 同请求重入不能重置预算或重复副作用 |
| 工具尝试记录 | 能力、指纹、attempt、状态、耗时、trace 引用 | 结果正文最小化；身份作用域隔离 |
| 人工请求关联 | 会话、接待标识、去重依据、状态、最后核实时间 | 结果未知可核实；并发请求不得重复建单 |
| Prompt 关联 | 请求所用 Prompt 版本/hash、模型与代码版本 | Prompt 正文由 Git 管理，不额外默认建版本库 |

具体数据库、表结构、索引、保留时间、清理任务在部署和接口评审后确定。待确定不等于无限期保存；生产上线前必须有明确保留与删除机制。

## 3. Agent 内部错误分类

以下为内部语义约定，暂不分配商城对外数值错误码或 HTTP 映射。

| 分类 | 处理 |
| --- | --- |
| INTENT_UNRESOLVED | 澄清，不默认为咨询 |
| INVALID_ACTION / INVALID_ARGUMENT | 拦截执行；预算允许时修复一次，否则兜底 |
| NEEDS_LOGIN / ACCESS_DENIED | 登录引导或拒绝；预期分支 |
| NO_MATCH / EVIDENCE_INSUFFICIENT | 无结果或缺依据，说明限制/澄清 |
| TOOL_TIMEOUT / TOOL_UNAVAILABLE | 仅合规只读请求按预算重试，否则降级 |
| MODEL_UNAVAILABLE / MODEL_REFUSAL | 区分技术失败与模型拒答；模板回复或人工 |
| BUDGET_EXHAUSTED / NO_PROGRESS | 终止新调度，固定模板结束 |
| RATE_LIMITED / SESSION_BUSY | 接纳前拦截，不调用模型 |
| HANDOFF_UNKNOWN | 核实接待状态，禁止盲目重建 |
| CANCELLED / STATE_CONFLICT | 停止工作或重新读取状态，不能覆盖新会话状态 |

业务错误沿用商城定义，接口提供后做显式映射；未知错误不能一律转换为 NO_MATCH。

## 4. 本地运行与测试环境说明

当前源码使用根目录 requirements.txt、config/app.yml、config/chroma.yml，通过 OPENAI_API_KEY 和 OPENAI_BASE_URL 变量读取模型配置。密钥只放本机环境或受控密钥存储，文档不包含真实值。

以下是当前原型的启动入口说明，未在本轮执行；安装会写环境、建库会写数据并可能产生 embedding 费用，不能当作已经验证的无副作用命令：

```powershell
Set-Location D:\desktop\PythonProject
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m rag.build_db
.\.venv\Scripts\python.exe -m streamlit run web.py
```

要求先存在可用虚拟环境且完成必要配置。现有知识库是商品文本原型，不是本设计的政策库验收数据；不能为测试直接重建或清空生产数据。

计划增加离线测试模式：注入固定模型响应与固定工具结果，独立临时状态存储，默认禁止真实网络，不需要真实 Key。当前项目尚无本方案所需的完整 mock 启动命令；实现后补命令，不能提前假定存在环境开关。

## 5. 编码与评审约定

- 工具负责验证、授权边界、业务调用和错误分类；Prompt 负责语义，不替代权限。
- 输入输出按最终契约校验，错误保留可审计分类；禁止异常吞掉后返回“没有结果”。
- 工具循环、重试、token 与限流预算集中管理，节点不能私设无限循环。
- Prompt 修改遵守 [03](03-prompts.md)；工具/状态修改关联 [04](04-evaluation.md) 用例。
- 只测试可观察契约：权限隔离、真实字段、幂等、终止、失败行为；不写只复制实现分支的测试。
- 接口未定时以业务期望评审，不提前制作假的生产适配层。
